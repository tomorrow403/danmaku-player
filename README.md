# DanmakuPlayer（开发中）

一个用于学习和验证「本地视频 + 网络弹幕」实现方案的 Web 端播放器原型。
当前处于开发调试阶段，尚未对外发布正式版本，目标是跑通
「视频文件识别 → 匹配番剧 → 拉取弹幕 → 播放器内叠加渲染」的完整链路。

- 在线演示：https://<你的用户名>.github.io/danmaku-player-demo/
- 源码仓库：https://github.com/<你的用户名>/danmaku-player-demo

> 演示页可直接打开，选择一个本机视频文件即可看到弹幕叠加效果；
> 不选视频也能观察渲染引擎行为（使用内置示例数据）。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建步骤，单文件即可运行）
- 弹幕渲染：DOM 元素 + Web Animations API（`element.animate`）
- 视频解码：浏览器原生 `<video>` + `URL.createObjectURL(File)`
- 后续计划：引入本地缓存（IndexedDB）保存弹幕与识别结果

## 计划接入的开放接口

```text
POST /api/v2/match                     视频文件识别，得到节目与剧集 ID
GET  /api/v2/comment/{episodeId}       获取对应剧集的弹幕
GET  /api/v2/search/episodes           按关键词搜索番剧与剧集
```

接口使用约定：

1. 仅用于本项目的功能实现，调用结果只在本地渲染与本地缓存中使用；
2. 不做二次分发、不对外提供接口、不将数据用于训练或转售；
3. 不采集、不存储用户个人信息，页面不包含任何追踪脚本；
4. 严格遵守弹弹play开放弹幕网络的使用规定与调用频率约定。

## 运行方式

方式一，直接打开：下载本仓库，双击 `index.html`。

方式二，本地静态服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

方式三，在线演示：见文首 GitHub Pages 地址。
