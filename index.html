DanmakuPlayer

原型 v0.1 本地渲染 · 无需服务端

本地视频弹幕播放器前端原型：选择本机视频即可叠加弹幕渲染。当前弹幕为内置示例数据，用于验证渲染引擎，尚未接入开放接口。

选择本地视频文件开始 也可以不选视频，直接查看弹幕渲染效果
状态：未加载视频 · 已渲染 0 条

已实现

  • 本地视频加载与播放控制（File API + objectURL）
  • 弹幕轨道分配与防重叠
  • 基于 WAAPI 的位移动画，暂停/恢复同步
  • 字号、透明度、速度、屏蔽词等渲染参数
  • 按播放时间轴触发弹幕，而非简单轮播

计划接入的开放接口

  • POST /api/v2/match 视频文件识别
  • GET /api/v2/comment/{episodeId} 弹幕获取
  • GET /api/v2/search/episodes 番剧搜索
  • 接口返回结果仅用于本地渲染与短期缓存
  • 不二次分发、不对外提供接口、不采集用户数据

说明

  • 纯前端单页，无后端、无数据库、无追踪脚本
  • 示例弹幕为自造文案，不代表任何真实接口数据
  • 视频文件仅在浏览器内解码，不会上传
  • 项目为学习与技术验证性质的原型
DanmakuPlayer Prototype · 单文件实现，可直接部署到 GitHub Pages 作为演示页面。
